# Restate Rust SDK v0.12.0 Release Notes

## Highlights

- **Typed ingress client** — the SDK now generates a `<Type>IngressClient` for every service, virtual object, and workflow, so you can invoke handlers from outside a Restate service
- **In-process Restate Cloud tunnel** — serve an endpoint over outbound HTTP/2 to Restate Cloud, with no inbound HTTP port required (Unix-only, behind the `tunnel` feature)

## New Features

### Typed ingress client

The SDK now generates a typed `<Type>IngressClient` for every impl-block service, virtual object,
and workflow. Ingress clients invoke handlers from outside a Restate service and require Restate
1.7 or newer.

Enable the `reqwest-client` feature to use the built-in reqwest client:

```rust
use restate_sdk::ingress::ReqwestClient;

let client = ReqwestClient::connect("http://localhost:8080".parse()?)?;
let greeter = GreeterIngressClient::from_client(client);
let greeting = greeter
    .greet("Ada".to_owned())
    .call()
    .await?
    .into_body()?;

println!("{greeting}");
```

To use another HTTP client, implement `RequestExecutor` and pass it to `Client::new`.

### In-process Restate Cloud tunnel

The SDK can now serve an endpoint over outbound HTTP/2 connections to Restate Cloud, so a
service no longer needs an inbound HTTP port. It is Unix-only and behind the non-default `tunnel`
feature (plus a crypto backend, `rust_crypto` or `aws_lc_rs`):

```toml
restate-sdk = { version = "0.12", features = ["tunnel"] }
```

The operator supplies the `RESTATE_INPROC_*` environment variables and a projected token Secret, so
the application just runs the tunnel:

```rust
use restate_sdk::prelude::*;

let endpoint = Endpoint::builder().bind(Greeter).build();
Tunnel::new(endpoint).run().await?;
```

`run()` handles SIGINT/SIGTERM: the first signal drains gracefully, a second forces close. For an
application-managed lifecycle, use `connect()` (returns after the first successful handshake):

```rust
let connection = Tunnel::new(endpoint).connect().await?;
println!("{}", connection.info().deployment_url());
connection.shutdown().await?; // graceful drain; or .close() for abrupt
```
